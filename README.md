## Обо мне

Интересуюсь OSINT, проверкой открытых источников и организацией исследовательской работы. Развиваю **OSINT Atlas** — локальную среду для поиска инструментов, заметок и связей между сущностями.

## Проект

**OSINT Atlas** объединяет каталог открытых ресурсов, граф связей и генератор Google Dorks. Приложение работает в браузере без backend; локальные заметки и настройки остаются в LocalStorage. Запросы к Google запускаются только по клику пользователя.
